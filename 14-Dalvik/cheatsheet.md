Printable. Tables and commands only. Full explanations in [README.md](README.md).

## 1. Register model

| Fact | Value |
|---|---|
| Register width | 32 bits |
| `long` / `double` | Two **adjacent** registers, named by the lower |
| Parameter location | The **last** `ins_size` registers of the frame |
| `pN` to `vN` | `pN == v(registers_size − ins_size + N)` |
| `p0`, instance method | `this` |
| `p0`, static method | First declared parameter |
| `.registers N` | N = **total** registers, parameters included |
| `.locals N` | N = locals **only**; assembler adds the parameters |
| 4-bit register field | `v0`–`v15` |
| 8-bit register field | `v0`–`v255` |
| 16-bit register field | `v0`–`v65535` |
| Max register entries in `35c` invoke | 5 **words** (a `long` counts as 2) |

## 6. Mnemonic suffix decoder

| Suffix | Meaning |
|---|---|
| `/2addr` | Destination is also the first source: `vA = vA op vB` |
| `/lit8` | Last operand is an 8-bit signed literal |
| `/lit16` | Last operand is a 16-bit signed literal |
| `/from16` | Source register field widened to 16 bits |
| `/16` | Both register fields widened to 16 bits |
| `/32` | Operand widened to 32 bits |
| `/high16` | Literal supplies the **high** bits; low bits zero |
| `/jumbo` | Constant-pool index widened to 32 bits |
| `/range` | Register list replaced by first-register + count; requires **contiguous** registers |
| `-wide` | Operates on a 64-bit register **pair** |
| `-object` | Operates on a reference |
| `cmpl-*` | NaN comparison yields **−1** |
| `cmpg-*` | NaN comparison yields **+1** |

| Fmt | Units | Shape | Fmt | Units | Shape |
|---|---:|---|---|---:|---|
| `10x` | 1 | opcode only | `22x` | 2 | vAA, vBBBB |
| `12x` | 1 | vA, vB | `23x` | 2 | vAA, vBB, vCC |

## 8. Verifier rules that break patches

| Rule | Failure |
|---|---|
| `move-result*` **immediately** follows its `invoke-*` | `VerifyError` at class load |
| `move-exception` is the **first** instruction of a handler | `VerifyError` |
| Register numbers < `registers_size` | Assembler rejects |
| Wide value must not straddle the frame end | Assembler / verifier rejects |
| Instruction family must match the type (`return-object` for `L…;`) | `VerifyError` |
| No fall-through into a payload | `VerifyError` |
| Uninitialised reference (between `new-instance` and `<init>`) must not escape | `VerifyError` |
| Branch targets on instruction boundaries | Assembler rejects |
| `try` range must cover ≥ 1 instruction | Assembler rejects |
| `monitor-enter` / `monitor-exit` balanced on every path | `VerifyError` or deadlock |

## 9. Patch recipes

| Goal | Smali |
|---|---|
| `boolean` → `true` | `const/4 v0, 0x1` `return v0` |
| `boolean` → `false` | `const/4 v0, 0x0` `return v0` |
| `int` → `0` | `const/4 v0, 0x0` `return v0` |
| `String` → constant | `const-string v0, "x"` `return-object v0` |
| Object → `null` | `const/4 v0, 0x0` `return-object v0` |
| `long` → `0` | `const-wide/16 v0, 0x0` `return-wide v0` |
| `void` → no-op | `return-void` |
| Invert a branch | `if-eqz` ↔ `if-nez` |
| Skip a block | `goto :after` before it |
| Delete an instruction, keep offsets | replace with `nop` |
| Overwrite a call result | after `move-result vX`: `const/4 vX, 0x1` |
| Log a value | after `move-result*`: `const-string v1, "TAG"` + `invoke-static {v1, v0}, Landroid/util/Log;->d(Ljava/lang/String;Ljava/lang/String;)I` |
| Non-String → String for logging | `invoke-static {v0}, Ljava/lang/String;->valueOf(I)Ljava/lang/String;` |
| `byte[]` → String | `invoke-static {v0}, Ljava/util/Arrays;->toString([B)Ljava/lang/String;` |

Remember: raise `.locals`/`.registers` for any new register, and never write raw `vN` for a parameter.

## 10. Commands

### Decode / rebuild

```bash
apktool d app.apk -o work/                 # full decode (Smali + resources)
apktool d -r -b app.apk -o work/           # Smali only, no debug directives -- much faster
apktool b work/ -o patched.apk
zipalign -p -f -v 4 patched.apk aligned.apk
apksigner sign --ks ~/.android/debug.keystore --ks-pass pass:android --out signed.apk aligned.apk
apksigner verify -v signed.apk
adb uninstall com.example.target ; adb install signed.apk
```

### Bare DEX

```bash
unzip -o app.apk 'classes*.dex' -d dex/
baksmali d dex/classes.dex -o smali/
baksmali d dex/classes.dex -o smali/ --api 34 --allow-odex-opcodes --no-parameter-registers
baksmali list classes dex/classes.dex
smali a smali/ -o classes.dex --api 34
zip -j app.apk classes.dex
```

### Inspect

```bash
dexdump -d classes.dex                     # disassembly with hex code units
dexdump -f classes.dex                     # header
jadx -d out/ --show-bad-code app.apk       # Java + Smali
adb logcat -s art:* AndroidRuntime:*       # verifier rejections
adb shell pm path com.example.target       # find the installed APK
```

### Chapter tooling

```bash
python3 scripts/smali_stats.py work/ --top 25
python3 scripts/smali_stats.py work/ --heuristics
python3 scripts/smali_frame.py work/smali/com/example/Foo.smali
python3 scripts/smali_frame.py work/ --check          # scan a whole tree for register hazards
./scripts/smali-hunt.sh work/
frida -U -f com.example.target -l scripts/trace-method.js --no-pause
```

## 12. Recognition table

| Shape in Smali | Was in source |
|---|---|
| `StringBuilder` + `append` chain + `toString` | `"a" + b` |
| `hashCode()` → `sparse-switch` → `equals()` → `packed-switch` | `switch` on a `String` |
| `.catchall` + a body appearing twice | `try` / `finally` |
| `iterator()` / `hasNext()` / `next()` / `check-cast` | `for (T t : collection)` |
| `array-length` + index register + `aget-object` | `for (T t : array)` |

## 13. Historical Dalvik VM

| Item | Value |
|---|---|
| Introduced | Android 1.0 (2008), by Dan Bornstein |
| Named after | Dalvík, a village in Iceland |
| JIT introduced | Android 2.2 Froyo (2010) — a **trace** JIT |
| ART optional | Android 4.4 KitKat (developer option) |
| Dalvik removed | Android 5.0 Lollipop |
| Interpreter | `mterp`, hand-written assembly, **64-byte** handler stride |
| Dispatch | `table_start + (opcode * handler_size)` — a shift and an add |
| Install-time optimiser | `dexopt` — verify, quicken, byte-swap, record dependencies |
| ODEX magic | `dey\n` + `036\0` (plain DEX is `dex\n` + `036\0`) |
| ODEX location | `/data/dalvik-cache/data@app@<pkg>-N.apk@classes.dex` |
| JIT unit | A **trace** — one linear path, ending at a branch/call/return/throw |
| JIT thread | Separate; the app thread never blocked |
| Trace chaining | Exit branches patched to jump directly into the next trace |
| GC | Mark-and-sweep, non-compacting; concurrent marking from 2.3 |
| Fatal flaw | Nothing persisted — every process re-JITted at every launch |

| Surviving `dalvik.vm.*` property | Still read by ART |
|---|---|
| `dalvik.vm.heapstartsize` | Yes |
| `dalvik.vm.heapgrowthlimit` | Yes |
| `dalvik.vm.heapsize` | Yes |
| `dalvik.vm.checkjni` | Yes |
| `dalvik.vm.stack-trace-file` | Yes |
| `dalvik.vm.execution-mode` | **No** — Dalvik only |
| `dalvik.vm.dexopt-flags` | **No** — replaced by compiler filters |
