----------------------------------------------------------
We wrote sender_euid=0 into the outgoing transaction.
The receiver did not see it. binder_transaction() in
drivers/android/binder.c overwrites both sender fields from the
calling task's own kernel-held credentials before the target is
ever woken up. The field exists in the struct only because the
SAME struct is used for delivery, where the kernel fills it in.

Run the same command WITHOUT --forge-uid and diff the output.
They are identical. That is the proof.
